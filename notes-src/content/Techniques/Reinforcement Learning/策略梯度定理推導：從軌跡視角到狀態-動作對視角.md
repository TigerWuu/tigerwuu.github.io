# **📌 核心目標**

本筆記旨在推導並證明：策略梯度定理的**軌跡視角（Trajectory-level，式一）**，在數學上如何透過時間因果律與期望值展開，完美轉化為現代 Actor-Critic 常用的**狀態-動作對視角（State-Action level，式二）**。

# **🧮 待證明之兩大核心公式**

- **式一：軌跡視角 (Trajectory-level)**
    
    $\nabla_\theta \mathbb{E}_{\pi_\theta}[r(\tau)] = \mathbb{E}_{\pi_\theta} \left[ r(\tau) \left( \sum_{t=1}^T \nabla_\theta \log \pi_\theta(a_t \mid s_t) \right) \right]$
    

- **式二：狀態-動作對視角 (State-Action level)**
    
    $\nabla_\theta J(\theta) = \mathbb{E}_{s \sim d, a \sim \pi_\theta} \left[ \nabla_\theta \log \pi_\theta(s, a) Q^{\pi_\theta}(s, a) \right]$
    

# **🛠️ 完整推導步驟**

1. **展開式一的內部雙重加總**
首先，我們知道一條軌跡 $\tau$ 的總回報 $r(\tau)$ 是各個時間步獎勵的加總，即 $r(\tau) = \sum_{k=1}^T r_k$。將其帶入式一右側的期望值中：$\mathbb{E}_{\pi_\theta} \left[ \left( \sum_{k=1}^T r_k \right) \left( \sum_{t=1}^T \nabla_\theta \log \pi_\theta(a_t \mid s_t) \right) \right]$
利用代數分配律將這兩個加總（Summation）相乘展開，並根據**期望值的線性性質（Linearity of Expectation）**，將期望值符號 $\mathbb{E}$ 移入第一層加總之內，得到：$\sum_{t=1}^T \mathbb{E}_{\pi_\theta} \left[ \nabla_\theta \log \pi_\theta(a_t \mid s_t) \sum_{k=1}^T r_k \right]$
2. **導入時間因果律（Causality）**
對於任意特定的時間步 $t$，我們將總獎勵 $\sum_{k=1}^T r_k$ 拆解為兩部分：**過去與當前的獎勵 ($k < t$)**，以及**未來的獎勵 $(k \ge t)$**：$\sum_{t=1}^T \left( \mathbb{E}_{\pi_\theta} \left[ \nabla_\theta \log \pi_\theta(a_t \mid s_t) \sum_{k=1}^{t-1} r_k \right] + \mathbb{E}_{\pi_\theta} \left[ \nabla_\theta \log \pi_\theta(a_t \mid s_t) \sum_{k=t}^T r_k \right] \right)$

💡 **核心引理 (Causality Lemma)：**
在時間步 $t$之前就已經決定的歷史獎勵 $r_k (k < t)$，其數值與當前動作的選擇梯度完全獨立。在數學期望值上，**過去的獎勵對當前梯度的貢獻恆等於 0**。$\mathbb{E}_{\pi_\theta} \left[ \nabla_\theta \log \pi_\theta(a_t \mid s_t) \sum_{k=1}^{t-1} r_k \right] = 0$
因此，上式左半邊的歷史項直接歸零抹去，公式成功簡化為只看當前與未來回報的 **Reward-to-go** 形式：$\sum_{t=1}^T \mathbb{E}_{\pi_\theta} \left[ \nabla_\theta \log \pi_\theta(a_t \mid s_t) \sum_{k=t}^T r_k \right]$

1. **引入 Action-Value Function ($Q$ 函數)**
根據馬可夫決策過程（MDP）中，$Q$ 函數的標準微觀定義，它代表「在狀態 $s_t$ 下執行動作 $a_t$ 後，未來預期能拿到的累積折現回報」：$Q^{\pi_\theta}(s_t, a_t) = \mathbb{E}_{\pi_\theta} \left[ \sum_{k=t}^T r_k \;\middle|\; s_t, a_t \right]$
利用條件期望式的**重複取期望值法則（Law of Total Expectation）**，我們可以將內部的 Reward-to-go 項直接用 $Q$ 函數替換，將公式改寫為：$\sum_{t=1}^T \mathbb{E}_{s_t, a_t \sim \pi_\theta} \left[ \nabla_\theta \log \pi_\theta(a_t \mid s_t) Q^{\pi_\theta}(s_t, a_t) \right]$
2. **從時間加總轉換為長期狀態分佈**
最後，我們處理最外層對時間步的加總 $\sum_{t=1}^T$。
智能體在所有時間步 $t$ 所經歷的狀態的平均，在數學上等價於「智能體在長期運行下，訪問到各個狀態的**長期狀態訪問頻率（Discounted State Stationary Distribution，通常記為 $d(s)$）**」。$\sum_{t=1}^T \mathbb{E}_{s_t \sim \text{環境}} [ \dots ] \equiv \mathbb{E}_{s \sim d} [ \dots ]$
因此，我們將時間加總與時間下標 $t$ 移除，正式收攏為整個狀態空間與動作空間的長期期望值形式：$\mathbb{E}_{s \sim d, a \sim \pi_\theta} \left[ \nabla_\theta \log \pi_\theta(s, a) Q^{\pi_\theta}(s, a) \right]$\

# **🏁 最終結論**

經過上述四個階層的推導，我們成功證明：$\nabla_\theta \mathbb{E}_{\pi_\theta}[r(\tau)] = \mathbb{E}_{s \sim d, a \sim \pi_\theta} \left[ \nabla_\theta \log \pi_\theta(s, a) Q^{\pi_\theta}(s, a) \right]$
這說明了**式一與式二在數學本質上是完全等價的**。

- **式一（REINFORCE）**：是以整條軌跡為單位，實作簡單但方差大。
- **式二（Actor-Critic）**：是以單步為單位，透過引進 $Q$ 函數估計，能大幅降低方差，這也是現代 PPO、SAC 演算法更為穩定的數學根基。
