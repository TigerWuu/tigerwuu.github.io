Introduction

  • Planning vs. Reinforcement Learning

    • Planning: there is environment (model) information, transition probability, and reward
    • Reinforcement Learning: No environment (model) information, transition probability, and reward
    PlanningReinforcement Learning
    Transition probabilityVX
    RewardVX

  • Prediction vs. Control

    • Prediction: giving a fixed policy to evaluate the future
    • Control: find the best policy π to optimize the future

  • MP vs. MRP vs. MDP

    • Markov process (MP): <S,P>
    • Markov reward process (MRP): MP + reward → <S,P,R,γ>
    • Markov decision process (MDP) MRP + action → <S,A,P,R,γ>

  • Bellman Equation

    V(s)=R(s)+γs′∈S∑​P(s′∣s)V(s′) v=R+γPv

    • Direct solution

      v=(I−γP)−1R

    • Iterative solution

      • Dynamic programming (known environment)
      • Monte Carlo evaluation (unknown environment)
      • Temporal difference evaluation (unknown environment)

  • Bellman Expectation Equation vs. Bellman Optimality Equation

    • Bellman expectation equation: evaluate the value/action value function under a fixed policy

      • State value equation

        vπ​(s)=a∈A∑​π(a∣s)qπ​(s,a)(Rsa​+γs′∈S∑​Pss′a​vπ​(s′))​​

      • Action value equation

        qπ​(s,a)=Rsa​+γs′∈S∑​Pss′a​vπ​(s′)a′∈A∑​π(a′∣s′)qπ​(s′,a′)​​
    • Bellman optimality equation: evaluate the value/action value function under the best policy

      • State value equation

        v∗​(s)=amax​(Rsa​+γs′∈S∑​Pss′a​v∗​(s′))

      • Action value equation

        q∗​(s,a)=Rsa​+γs′∈S∑​Pss′a​a′max​q∗​(s′,a′)

  • Dynamic programming

    For solving the Bellman equation

    ProblemBellman EquationAlgorithm

    • Policy iteration: find the current best action (a) as a policy π(a∣s) to update the value function (v(s))
      • policy evaluation (value function v(s)) + policy improvement (e.g. greedy algorithm)
    • Value iteration: keep finding the best action value function (q(s′,a′)) from the future to update the current value function (v(s))

    • Prediction

      • Monte Carlo: No boostrapping, termination.

        V(s)=Returntotal​(s)/N(s)

        Returntotal​(s) : incremental total return

        N(s): incremental counter

        V(s)←V(s)+N(s)1​(Gt​−V(s))↓V(s)←V(s)+α(Gt​−V(s))

        Gt​: current return

        α: step size, ∈[0,1]

      • Temporal Difference: boostrapping, no need termination state.

        V(st​)←V(st​)+α(Gt​−V(st​))↓V(st​)←V(st​)+α(R+γV(st+1​)−V(st​))

        Rt+1​+γV(st+1​): TD target

        Rt+1​+γV(st+1​)−V(st​): TD error

      • TD(λ): n-step temporal difference

    • Control

      • MC control

        policy evaluation (action value function q(s,a))+ policy improvement (ϵ-greedy algorithm)

        q(s,a)←q(s,a)+α(Gt​−q(s,a))

        • ϵ-greedy algorithm proof

      • SARSA

        q(st​,at​)←q(st​,at​)+α(R+γq(st+1​,at+1​)−q(st​,at​))

        Choose at​ from st​ using ϵ-greedy algorithm

      Goal: find a parameter vector w minimizing mean-squared error between the true value function vπ​(s) and its approximation v^(s,w)

      w : neural network parameters

      💡

      generalize from seen states to unseen states

          Δw=α(vπ​(S)−v^(S,w))∇w​v^(S,w)

        • How to solve ∇w​v^(S,w)? Ans: Represent the value function by a linear combination of features

          Feature

          x(S)=[x1​(S)x2​(S)...xn​(S)]⊤
          💡

          Features (x(S)) can be obtained from observation (feature engineer) or an encoder (learning-based)

          value function by a linear combination of features

          v^(S,w)=x(S)⊤w=j=1∑n​xj​(S)wj​

          The loss function and update Δw can be represented as follows

          J(w)=Eπ​[(vπ​(S)−x(S)⊤w)2]

    • Policy gradient

      Goal: given a policy πθ​(s,a) with parameters θ, find best θ

      πθ​(s,a)=P[a∣s,θ]
      💡

      πθ​(s,a) 意思是 a 在 當下 s 以及參數 θ 的 條件機率

      πθ​(s,⋅) 意思是在 s 以及參數 θ 的情況下 a 的條件機率分布(e.g. gaussian)

      • How to measure the quality of πθ​(s,a) ? → How do we define how best θ is?

        • Episodic environments: start value

          J(θ)=Vπθ​(s1​)=Eπθ​​[v1​]

        • Continuing environments

          average value

          J(θ)=s∑​dπθ​(s)Vπθ​(s)

          Average Reward per time-step

          J(θ)=s∑​dπθ​(s)a∑​πθ​(s,a)Rsa​
          • dπθ​(s): 在 πθ​ 這個policy 下，平均停留在 state s 的機率
          • ∑a​πθ​(s,a)Rsa​: 在 πθ​ 這個policy下，這個state s 獲得Reward的期望值
          💡

          如果action 跟 state 是連續的，公式應該改成積分式, e.g. JavR​(θ)=∫S​dπθ​(s)∫A​πθ​(a∣s)Rsa​dads

      Goal: Find θ that maximizes J(θ)

      θnew​=θold​+Δθ Δθ=α∇θ​J(θ)

      ∇θ​J(θ)=[∂θ1​∂J(θ)​ ⋯ ∂θn​∂J(θ)​​]⊤: policy gradient

      Goal: Compute ∇θ​J(θ) → compute the ∇θ​πθ​(s,a)

      Goal: Compute the ∇θ​πθ​(s,a)

      ∇θ​πθ​(s,a)​=πθ​(s,a)πθ​(s,a)∇θ​πθ​(s,a)​=πθ​(s,a)∇θ​logπθ​(s,a)​

        πθ​(s,a)∇θ​πθ​(s,a)​​=πθ​(s,a)1​⋅dθdπθ​(s,a)​=dπθ​(s,a)dlogπθ​(s,a)​⋅dθdπθ​(s,a)​=dθdlogπθ​(s,a)​=∇θ​logπθ​(s,a)​

        We try to maximize the estimation of total reward J(θ)

      • Policy gradient for multi-step MDP → introduce policy gradient theorem

        We try to maximize the estimation of total reward J(θ)

        trajectory τ=(s0​,a1​,s1​,a2​,…,sT​)

        trajectory total reward r(τ)

        J(θ)​=Eπθ​​[r(τ)]=∫πθ​(τ)r(τ)dτ​ ∇θ​J(θ)​=∇θ​∫πθ​(τ)r(τ)dτ=∫∇θ​πθ​(τ)r(τ)dτ=∫πθ​(τ)∇θ​logπθ​(τ)r(τ)dτ=Eπθ​​[r(τ)∇θ​logπθ​(τ)]​

        How to get ∇θ​logπθ​(τ) ?

        πθ​(τ)=1. 初始狀態機率P(s0​)​​×2. 策略大腦的選擇 (連乘)t=1∏T​πθ​(at​∣st​)​​×3. 環境物理轉移 (連乘)t=1∏T​p(st+1​∣st​,at​)​​ logπθ​(τ)=logP(s0​)+t=1∑T​logπθ​(at​∣st​)+t=1∑T​logp(st+1​,rt+1​∣st​,at​) ∇θ​logπθ​(τ)=t=1∑T​∇θ​logπθ​(at​∣st​)

        Put ∇θ​logπθ​(τ) back into gradient of the estimation of the total reward ∇θ​J(θ)

        ∇θ​J(θ)=Eπθ​​[r(τ)(t=1∑T​∇θ​logπθ​(at​∣st​))]

        Gradient ascent

        θt+1​=θt​+α∇θ​J(θt​)
        💡

        By the policy gradient theorem, we don’t need to know

        1. Ergodic distribution of states (P)
        2. Environment dynamics (p)

        We can still obtain the policy gradient through sampling.

  • TRPO: Trust region policy optimization

    • on-policy, actor-critic, continuous action

    • Constraint the policy changes so that we do not make too aggressive moves

    • We want to

      1. guarantee the improvement in rewards
      2. limit the change in the policy behaviors

    • Minorize-maximization algorithm (MM algorithm)

      1. Find a lower bound M approximating the expected reward η locally at the current guess

      2. We locate the optimal point for M and use it as the next guess

    • Optimization strategy

      1. line search → like gradient descent/ascent
      2. trust region → First decide the step size α and then construct a region (i.e., trust region) by considering the α as the radius of the circle
      💡

      Why is the trust region better than line search?

      trust region can avoid a saddle point optimization situation.
